## 1. プロジェクト管理

### 新規作成

1. 左サイドバー「新規プロジェクト」
2. 作成先フォルダを選び、プロジェクト名を入力
3. `<フォルダ>/<名前>/` が作られ、`manga.json` と `assets/` が生成される

### 既存を開く

- 左サイドバー「プロジェクトを開く」→ `manga.json` を含むフォルダを選択

### 保存

- **自動保存**: 編集から 1 秒後にデバウンス保存。ページ切替時にも保存
- **手動保存**: `Cmd/Ctrl + S`
- **終了時**: アプリ終了直前に未保存分を同期 flush

保存ステータスは上部に表示される（「保存済み 12:34:56」「保存中...」「保存エラー」）。

## 2. ページ

- **左サイドバー「ページ」リスト**で全ページを表示
- **追加**: リスト下の「＋」
- **並べ替え**: ドラッグ
- **削除**: ページ右クリック or 選択して操作
- **ページ名**は `001` `002` ... の連番に自動正規化される
- **ページサイズ**: 右サイドバー「ページ」→ `pageWidth` / `pageHeight`（デフォルト 840×1188）
- **ページ背景**: 単色 / グラデーション（linear / radial）/ 背景画像（[§7](#7-スクリーントーン背景画像)）

---

## 3. コマ（パネル）

### 追加

- 上部ツールバーの形状アイコンをクリック → ページ内の空きスペースに自動配置
- 配置ロジック（`utils/panelInsertion.ts`）:
  - 空ページ → 右上から 10px 余白で標準サイズ
  - 最下段の左端コマが幅 80% 以下で左余白があれば、その左隣に並べる
  - 下端に標準サイズ（高さ 300px）が入る余白があればそこに置く
  - 残り高さが 100〜300px なら高さを縮めて入れる
  - 残り高さが 100px 未満ならページ中央に配置

### 形状

| `PanelType` | 説明 |
| --- | --- |
| `rect` | 矩形 |
| `slanted` | 斜め矩形（`slant` で傾き調整） |
| `trapezoid-h` | 横向き台形（上下辺の長さが違う） |
| `trapezoid-v` | 縦向き台形（左右辺の長さが違う） |
| `pentagon` | 五角形 |
| `hexagon` | 六角形 |
| `circle` | 円 |

`slant` / `offsetB` / `offsetC` / `offsetD` で各形状を微調整。

### 移動・リサイズ・回転

- **移動**: ドラッグ。グリッド ON で吸着。Shift+矢印で 1px 単位
- **リサイズ**: Transformer のハンドル。回転ハンドルは無し
- **回転**: 右サイドバー「コマ」→ 回転スライダー
- **整列ガイド**: 移動中に他コマや斜辺と平行になると赤い線がガイド表示される

### 前後関係

右サイドバー「コマ」のボタン: 最前面 / 最背面 / 前へ / 後ろへ。

### コマ削除

- 画像が**ない**コマ: `Backspace` / `Delete` でコマ自体を削除
- 画像が**ある**コマ: `Backspace` / `Delete` で画像だけクリア（`isGrayscale` / `grayscaleBrightness` もリセット）。コマ自体は残る

## 4. 画像の挿入と編集

### ドラッグ&ドロップ

- ファイルをコマの上にドロップ
  - 画像がないコマ → **背景画像**として設定
  - 画像があるコマ or 2 枚目 → **素材**として追加（自動でクリップされる）
- コマ外にドロップ → 全体に対する**素材**として追加

### Shift オーバーレイ編集

コマを選択した状態で **Shift キー押下** → コマ内に編集タブが現れる。

| モード | 操作 |
| --- | --- |
| 移動 | ドラッグで画像を平行移動 |
| 拡大縮小 | 上ドラッグで拡大 / 下ドラッグで縮小 |
| 回転 | 右ドラッグで右回り / 左ドラッグで左回り |

追加トグル: **グレースケール** / **左右反転**。

### グレースケールの明るさ調整

- コマ・素材で `isGrayscale` を ON にすると、右サイドバーに明るさスライダー（-0.5 〜 +0.5）が出現
- Konva の Brighten フィルターを使用

## 5. 吹き出し

### 追加

1. コマを選択
2. 上部ツールバーから吹き出し種類アイコンをクリック → 選択コマの中心に追加

### 種類

| `BubbleType` | 形状 |
| --- | --- |
| `rounded` | 角丸 |
| `jagged` | ギザギザ |
| `rect` | 矩形 |
| `flash` | フラッシュ（ウニ） |
| `shout` | シャウト |
| `square-jagged` | 角型ギザギザ |
| `megaphone` | メガホン |
| `rect-double` | 二重矩形 |

### テキスト編集

- 吹き出しをダブルクリックで編集モード
- 縦書き / 横書き切替（右サイドバー）
- 行間 (`lineHeight`) / 字間 (`letterSpacing`)
- フォントファミリー、色、太さ 3 段階 (`textWeightLevel`)、縁取り (`textStrokeColor` / `textStrokeWidth`)
- 掠れ (`textRoughness` 0..1)
- **テキスト相対オフセット**: `Shift + ドラッグ`（吹き出し選択中）で吹き出し本体を動かさずテキスト位置だけ調整

### 自動フィット（`autoFitMode`）

- **`expand-bubble`**（デフォルト）: 文字サイズを保ち、枠を広げる
- **`shrink-font`**: 枠を保ち、文字を縮める
- **`off`**（手動）: いっさい自動調整しない

> **マウスハンドルで吹き出しをリサイズした瞬間、自動的に `off` に切り替わる**。ユーザーが手動で枠サイズを決めた以上は自動調整しない、という仕様。

### しっぽ操作

- 右サイドバーから `tailType`: `point`（普通）/ `thought`（思考）切替
- しっぽ先端を直接ドラッグで移動
- 制御点（`tailControlX/Y`）でカーブ調整、太さ (`tailWidth`)、フラッシュ系では `spikeCount` / `flashLength` / `narrowRatio`

### クリップ表示

- 右サイドバーの「コマ内クリップ」トグルで `isClipped` を ON にすると、選択中コマの形状で吹き出しがくり抜かれる
- 同種・同色などで自動グループ化される（クラスター描画）

### タイプ別の最終スタイル記憶

各 `BubbleType` ごとに、最後に編集した時のスタイル（フォント・色・縁取り等）が `localStorage` に保存される（キー: `manga-yarou-bubble-last-style-v1`）。
次に同じタイプを追加するとそのスタイルが初期値になる。位置・テキスト内容・しっぽ先端は除外。

## 6. 素材

- 画像をドロップ → 素材として追加
- 右サイドバー「素材」プロパティ:
  - 不透明度、回転、サイズ
  - グレースケール（+ 明るさスライダー）
  - **白飛び除去**（Alpha Threshold）: 白に近いピクセルをアルファ 0 に
  - コマ内クリップ（`isClipped` + `panelId`）
- `Backspace` / `Delete` で削除

## 7. スクリーントーン・背景画像

### モーダルを開く

- 左サイドバー「ツール」展開 → 「背景ライブラリ」or トーンアイコン
- 選択中コマの中心 X 位置に応じて左右どちらかに **固定サイドパネル**（`w-80`）で表示。キャンバスを隠さずリアルタイム確認

### 3 タブ

| タブ | 内容 |
| --- | --- |
| **内蔵トーン** | アプリ組み込みのスクリーントーン（網点・ハッチングなど） |
| **カスタムトーン** | **アプリ全体共有**の透過 PNG トーン。`app.getPath('userData')/custom-tones/` に保存 |
| **マイ画像** | **プロジェクト固有**の画像ライブラリ（`assets/references/backgrounds/`） |

カスタムトーンとマイ画像は **ドロップ or ファイル選択で登録**、名前編集、削除可能。

### 適用先

ラジオで選択:

- **ページ全体**: ページの `backgroundImagePath` 等に書き込む
- **コマ背景**: コマ画像の**下**に重なる（`backgroundImagePath` / `backgroundImageOpacity` ...）
- **コマ前面**: コマ画像の**上**に重なる（`fgTonePath` / `fgToneOpacity` ...）

### 共通スライダー

- 不透明度、スケール、回転、ぼかし（max 10、0.5 刻み）、X 移動、Y 移動
- **フェードアウト**: 3×3 グリッドの方向ボタン（8 方向の複数選択、中央クリア） + 強さスライダー

### 内部実装メモ

- ぼかしは **CSS filter（`ctx.filter = 'blur(Xpx)'`）で事前 canvas に焼く**。Konva の `fillPattern` + Blur フィルターは白くなるバグがあるため
- フェードは `ToneFadeOverlay` を Rect の直後に重ねる。終端色は `toTransparent(bgColor)` で同色アルファ 0
- URL 解決 + canvas 生成は `hooks/useTonePattern.ts` に一元化

## 8. モザイク

ページ上に**楕円形フェザリングのモザイク領域**を複数配置できる機能。

### 種類（`MosaicType`）

| 種類 | 内容 |
| --- | --- |
| `pixel-12` | 12px ブロック平均色モザイク |
| `frosted` | 摺りガラス（強ぼかし + 薄白オーバーレイ） |
| `white-blur` | 単純白塗り |
| `none` | 透明（編集時のみ枠表示） |

### 描画

- 左サイドバー「モザイク」をモード ON → ドラッグで領域を描画
- 既存領域を**選択した状態でタイプボタン**を押すとその領域のタイプだけが変わる
- 何も選択していない状態でタイプボタンを押すと「次に描く領域のデフォルト」が変わる
- `Backspace` で選択中領域を削除

### 内部実装メモ

- 形状は楕円フェザリング（小 σ のガウシアンマスク。短辺 × 6% を σ に）
- DPR 対応（`getTransform().a` で物理ピクセル計算）
- 隣接領域とブロック境界が揃うよう `physX % blockSize` でオフセット
- モザイクレイヤーは**最上位**に描画。`sceneFunc` の `getImageData` がコマピクセルを正しく読めるようにするため

### キャラクターごとに持つ情報

- AI 背景除去ボタンから rembg を起動 → [§12](#12-背景除去rembg)

## 10. 背景ライブラリ

## 11. マジックワンドエディタ

クリックでフラッドフィル透過 PNG を作るフルスクリーン Canvas エディタ。

### 開き方

- 参照キャラクターモーダルの画像サムネイル → **はさみアイコン**

### 操作

- **クリック**: クリック箇所と「近い色（4-connected フラッドフィル）」を透過
- **許容差スライダー**: 0〜150（RGB ユークリッド距離）
- **Cmd/Ctrl + Z**: アンドゥ（最大 30 ステップ）
- **保存**: `<元ファイル名>_wand.png` として同じディレクトリに出力
- 透過部分は**市松模様**で可視化

## 12. 背景除去（rembg）

`isnet-anime` モデルでアニメ調イラストから背景を AI 除去。

### 起動

- 参照キャラクターモーダルや合成ツールの「背景除去」ボタン
- 内部で `rembgRemoveBackground(projectPath, inputRelativePath)` IPC を呼び出し
- 出力: 入力と同じディレクトリに `<元ファイル名>_nobg.png`

### 仕組み

- 配布版 DMG では `Contents/Resources/rembg/python/` に同梱された Python ランタイム + rembg を使用
- 開発時は `resources/bundled-rembg/<os>-<arch>/` を使用（`npm run bundle-rembg` 後）
- モデル `isnet-anime` は初回実行時に HuggingFace からダウンロード（ユーザー側でキャッシュ）

詳細・トラブルシューティング → [REMBG.md](REMBG.md)

## 13. NovelAI 画像生成

各コマに対し、NovelAI Image API を呼んで画像を生成。

### セットアップ

1. NovelAI の有効なサブスクリプション (Opus 推奨)
2. API トークンを取得 → アプリで設定（暗号化保存）

### 機能

- アスペクト比: portrait / square / landscape
- シチュエーションプロンプト + 補足プロンプト
- ネガティブプロンプトの上書き
- **参照キャラクター**を最大 6 体（自動で `character&style` 参照）
- **精密参照（vibe transfer）**を最大 2 件（参照キャラ画像 or 合成画像）
- シード固定 / ランダム
- 生成履歴をコマごとに保持

詳細 → [NOVELAI.md](NOVELAI.md)

## 14. 原稿メモ

プロジェクト全体の原稿（台詞ネーム）を書きながら、必要な箇所を吹き出しに転記できる機能。

### 使い方

1. 画面下の「原稿」パネルを開く（折りたたみ式）
2. テキストエリアに原稿を書く（自動保存）
3. 吹き出しにしたい台詞を**選択した状態**で、コマ選択 → 吹き出し追加
4. 選択していた文字列が吹き出しの初期テキストに入り、**原稿側からは削除される**

### 仕様

- 状態: `manuscript: string` / `manuscriptSelection: { start, end } | null`
- スライス: `store/slices/manuscriptSlice.ts`
- `manga.json` の `manuscript` フィールドに保存
- パネル開閉状態は `localStorage` (`manga-yarou-manuscript-panel-open`)
- 選択範囲は textarea の `onSelect` / `onKeyUp` / `onMouseUp` で更新

## 15. 合成ツール（背景＋人物）

背景画像と人物画像を組み合わせて 1 枚の合成 PNG を作るツール。

- 左サイドバー「ツール」→「合成」
- 背景レイヤー、人物レイヤーをそれぞれ選んで重ねる
- 出力は `assets/composites/<タイムスタンプ>.png`
- 出力した合成画像は NovelAI の精密参照（vibe transfer）にも使える

## 16. エクスポート

### 単一ページ PNG

- 左サイドバー「ツール」→「現在のページを PNG」
- 出力: `exports/<ページ名>.png`（例 `001.png`）
- `pixelRatio: 2` で書き出し（高 DPI）

### 全ページ一括 PNG

- 「全ページ一括 PNG」
- 内部で順次 `selectPage` → `flushSync` → 短い `setTimeout` → `toDataURL`
- `selectPage(..., { skipAutosave: true })` で書き出し中の自動保存をスキップ
- 完了後に元のページへ戻し、保存

### セリフ TXT

- 「セリフ TXT」
- 全ページの全吹き出しテキストをページ・吹き出し順に書き出し
- 出力: `exports/<プロジェクト名>.txt`

### エクスポート時の表示

- `isExporting` フラグで Transformer・グリッド線などを一時非表示
- グリッド線描画箇所は `!isExporting` ガード必須（**ガードがないと PNG に焼き込まれる**）

## 17. テンプレート

ページレイアウト（コマ配置）を保存・再利用する機能。

### 保存

- 左サイドバーから「現在のページをテンプレに保存」
- 名前を入力 → `app.getPath('userData')/templates.json` に保存（プロジェクト外）

### 適用

- 「テンプレ」モーダル → 適用したいテンプレを選択 → 現在のページに適用

### 仕様

- 型: `{ id, name, panels: Omit<Panel, 'id'>[] }`
- **画像関連フィールドは除外して保存**（テンプレを別プロジェクトで使えるように）。`imagePath`、`isGrayscale`、`grayscaleBrightness` 等

---

## 18. アセット整理

- 左サイドバー「Assets」セクション
- プロジェクト内のすべての画像ファイル一覧
- 未使用と判定されたファイルに「整理」ボタン → `assets/dust/` へ**移動**（削除はしない）
- IPC 名は互換のため `move-asset-to-trash` のまま
- `dust/` のファイルは整理対象外（再整理されない）
